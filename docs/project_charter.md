## 1. 项目背景与目标

### 1.1 战略定位
一套独立于准我（量化多因子）、超我（交易心理）、郭睿（Wyckoff+混沌）的**纯价格行为交易系统**。基于 Al Brooks 价格行为学三部曲，100% 基于价格形态与市场结构，不依赖技术指标。

### 1.2 项目目标
构建一套可运行的 A 股价格行为交易系统，覆盖：
1. **市场状态分类** — Always-In 方向 + 趋势/区间/反转三态判定
2. **形态识别** — High/Low计数、信号K线、反转形态、区间形态
3. **策略生成** — 趋势跟随、区间交易、反转交易三大策略族
4. **风控执行** — T+1/涨跌停适配 + 交易者方程仓位管理
5. **回测验证** — 2018-2026 回测 + 绩效归因

### 1.3 成功标准

| 维度 | 指标 | 目标 |
|------|------|------|
| 功能完整性 | 三书核心概念实现覆盖率 | >= 80% |
| 状态分类 | Always-In方向判断准确率（整体） | >= 65% |
| 状态分类 | Always-In分层验收：强趋势日 | >= 75% |
| 状态分类 | Always-In分层验收：区间日 | >= 55% |
| 回测收益 | 年化收益（扣除费率，前提：月均信号>=3） | > 10% |
| 回测风控 | 最大回撤 | < 20% |
| 回测风控 | 夏普比率（日线策略区间） | > 0.4 |
| 信号密度 | 月均交易信号数 | >= 3 |
| 可操作性 | 每日产出 ≤ 5 只选股 | 日均输出 |

## 2. 系统架构

### 2.1 六层架构

```
┌─────────────────────────────────────────────┐
│            L6: 输出层 (Signal Output)         │  每日信号清单 + 复盘报告
├─────────────────────────────────────────────┤
│            L5: 风控层 (Risk Control)          │  仓位管理 / 止损规则 / T+1适配
├─────────────────────────────────────────────┤
│            L4: 策略层 (Strategy)              │  趋势跟随 / 区间 / 反转
├─────────────────────────────────────────────┤
│            L3: 形态识别 (Pattern Engine)  ←─── │  High/Low计数 / 信号K线 / 反转形态  ←──┐
├─────────────────────────────────────────────┤                                     │ 反馈回路
│            L2: 状态分类 (State Classifier) ──── │  Always-In / 趋势强度 / Spike+Channel ───┘ (L3→L2置信度校准)
├─────────────────────────────────────────────┤
│            L1: 数据层 (Data Layer)            │  K线获取 / 缓存 / 预处理
└─────────────────────────────────────────────┘
```

### 2.2 模块依赖关系

```
L1 数据层 ──→ L2 状态分类 ──→ L3 形态识别 ──→ L4 策略层 ──→ L5 风控层 ──→ L6 输出层
                  ↑_______________│
                  L3→L2 反馈回路 (context_feedback.py)
     │                │               │              │             │
     │                ↓               │              │             │
     └─────────── 回测引擎 ←──────────┴──────────────┴─────────────┘
```

### 2.3 技术选型

| 层 | 技术 | 理由 |
|----|------|------|
| 语言 | Python 3.10+ | 与现有系统一致 |
| 数据 | Tushare Pro | 与准我共用，复用 `loader.py` |
| 计算 | pandas + numpy | 向量化 K 线计算 |
| 存储 | CSV 本地文件 | 原型期无需数据库 |
| 回测 | 自研 | Al Brooks 策略需定制回测逻辑 |
