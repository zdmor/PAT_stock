# PAT 路线图 — 60 分钟主框架版

> 基于 M1.5 日线密度探测 FAIL（中位数 0.25 信号/月）
> 决策：60 分钟线主框架，日线退为趋势过滤
> 创建日期: 2026-06-14

---

## 总体原则

- **怎么快怎么来**：Tushare 2000积分 + 免费API混用，性能优先
- **最简路径到可运行信号**：先出东西再迭代
- **不做什么**：M2.5 趋势日七分法跳过，反转/区间策略不做MVP

## 架构图（60 分主框架）

```
日线 (趋势过滤)
  └→ Always-In 方向 + 趋势强度 → 只允许顺趋势方向的信号
                                      │
60 分线 (主交易框架)                    │
  ├→ Always-In (窗口参数按 60 分重标)    │
  ├→ 关键位 (容差重新校准)              │
  ├→ 信号 K 线 (Pinbar + 其他)          ← 日线方向约束
  └→ High/Low 计数 → 策略引擎
                                      │
策略输出 → 基础风控 → 信号清单
```

## 跳过/延迟项

| 项 | 理由 | 计划 |
|----|------|------|
| M2.5 趋势日七分法 | 60 分线 Always-In None 率低，七分法无必要 | 永久跳过 |
| 反转形态完整库 | MVP 只做趋势跟随 | Phase 3 |
| 区间形态完整库 | MVP 不交易区间 | Phase 3 |
| 反馈回路 | 需要数据积累才有意义 | Phase 3 |
| 集成冒烟测试 | 随做随测 | 不单独设阶段 |
